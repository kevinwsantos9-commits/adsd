# Nivek First Person

Mod **Fabric 1.21.1 (Java 21)** que mostra o corpo inteiro do jogador na câmera em primeira pessoa.

- Ao olhar para baixo você vê o corpo, os braços e as pernas.
- A cabeça, o capacete e itens na cabeça ficam escondidos para não cobrir a tela.
- Funciona só no cliente; não precisa instalar no servidor.

## Compilar pelo GitHub Actions

1. Crie um repositório e envie todos os arquivos desta pasta (inclusive a pasta oculta `.github`).
2. Aba **Actions** > **Build Nivek First Person** > baixe o artefato `nivek-first-person-1.21.1`.
3. Extraia o ZIP e copie o `.jar` para `%appdata%\.minecraft\mods`.

## Para jogar

Minecraft 1.21.1, Fabric Loader 0.16.0+, **Fabric API 1.21.1** (na mesma pasta `mods`) e Java 21.
